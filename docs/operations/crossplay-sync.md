# 选择 PC / PE 进度并同步

新版账号菜单支持选择进度来源。两端各完成一次服内注册登录；不必同时在线，也不要求名字相同。

1. 同一 IP 的另一平台账号已有登录记录时，后来的玩家会收到“是否同步 PC/PE · 账号的进度”提示。可以忽略，之后从指南针账号中心，或 `/miao sync` 手动选择。IP 只决定候选提示，不授予身份。
2. 选择自己的另一个平台账号，再选择保留哪份进度。菜单标出先玩的账号作为推荐，但最终由玩家选定。
3. 验证另一个账号的**服内密码**；当前账号也必须已通过 AuthMe 登录。不输入 Xbox 密码。密码不会写入身份日志、配置或聊天广播。
4. 成功后两端退出并重新连接。Java 登录名保持原样；PC/PE 都使用 Java 账号的服内密码。进度来源提醒会写出平台和原账号，每次登录均可看到。

Java 菜单用下一条聊天收取密码，输入“取消”退出，两分钟有效，超时的这条输入也不会广播。PE 使用原生表单；原生输入框显示输入文字，避免在旁人能看到屏幕时输入。每个被验证账号至少间隔十秒可再次验证。

两端使用选定那份进度的原有 UUID。选择 PE 时，Java 登录映射到 PE 原 UUID；选择 Java 时，PE 通过 Floodgate 使用 Java UUID。因此原版背包/末影箱/经验/进度、UUID 归属的金币/家/领地/队伍/奖励/技能/昵称备注继承同一份数据，无需逐个复制数据库。另一份旧 UUID 数据保留，不合并物品、金币和领地。创造背包仍然隔离。

`/unlinkaccount` 会引导确认，或 `/miao sync unlink confirm` 明确解除；两端重连后恢复各自原有 UUID。保留下来的那份进度包含绑定期间发生的变化；另一份独立旧进度仍是之前的内容。系统不把绑定期间的变化复制成两份。

已有原 Floodgate 绑定不会被覆盖；需先解除，才能在新菜单重新选择来源。原 `/linkaccount` 验证码流程仍按 Floodgate 使用 Java 进度，要继承 PE 进度请用新菜单。

## 运维

运行数据 `plugins/MiaoServer/crossplay-sync.yml` 保存带随机盐的 IP 摘要、账号 UUID、进度来源与绑定日志，**不保存密码**。它与 Floodgate 本地 SQLite 绑定库一起随插件目录备份；禁止单独删除身份日志，否则 Java 无法继续找到 PE 来源存档。账号首次绑定另保存一份操作前的小型身份日志副本。

绑定写入前保存日志并让两端退出；在两个 Tick 周期后调用 Floodgate，本地绑定回读匹配才开放重连。启动先核对既有日志与 Floodgate；未完成或不一致时阻止受影响账号进入，保留数据供核对。数据库暂不可用每分钟重试。解除由同一入口协调两个身份存储。

IP 摘要使用服务端看到的连接地址。云端转发隐藏/改变来源地址时，同 IP 提示可能不可用或显示同网络的其他人，手动绑定仍可用，且始终需要密码验证。插件不使用 IP 或相同名字直接免密登录。

本地启动测试覆盖两种源 UUID、Paper 登录资料、同 IP 候选、私密输入、真实 AuthMe 密码验证、Floodgate SQLite 绑定/解除。**实际 Java/PE 网络登录、背包往返、金币领地、创造隔离、重启后的客户端验收仍待云服进行。** 自行添加按名字存储数据的插件需要单独核查，不保证名称数据库自动迁移。
