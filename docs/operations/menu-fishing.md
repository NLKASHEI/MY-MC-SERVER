# 中文玩家中心与钓鱼奖励

右键生存指南针，或执行 `/menu` 打开玩家中心。主界面 54 格，采用浅蓝、灰色玻璃边框，按世界探索、家园圈地、成长奖励、休闲工具分区；子菜单有固定返回按钮，左右键执行相同动作。

| 界面 | 入口与操作 |
|---|---|
| 玩家中心 | `/menu`，各功能入口、余额与付款说明 |
| 世界选择 | 主城、生存、隔离背包的创造超平坦 |
| 家园管理 | 回家、设置“家园”、多个家使用说明 |
| 好友传送 | 发起申请说明、接受、拒绝、聊天命令 |
| 领地管家 | 金铲划地教程、快速圈地、领地列表、授权说明、查看权限、防卡住 |
| 放弃领地确认 | 仅取消脚下当前领地的保护，需要再次点击确认；建筑保留 |
| 生电助手 | 创建、检查、持续攻击、持续使用、停止、移除自己的假人 |
| 钓鱼图鉴 | 奖励分档说明、打开钓鱼技能界面 |
| 互动休闲 | 坐下、躺下、爬行、骑头开关等 |
| 账号设置 | 双端绑定、绑定步骤、改密说明、规则 |
| 交易中心 | `/market`，补给商店、玩家箱子商店、开店教程 |

需要玩家名或密码的操作展示中文命令说明，玩家自行输入。菜单不会捕获密码。家园快捷设置使用固定名称“家园”，再次设置会覆盖同名坐标。圈地采用 GriefPrevention 的生存领地，不是固定尺寸地皮；首次使用准备金铲，系统按可用领地额度判断能否创建。

## 钓鱼奖励

配置源为 `config/survival/plugins/AuraSkills/loot/fishing.yml`。总计 54 项：稀有 24、史诗 24、珍藏 6。三池都要求开放水域，不能在主城、创造区或创造模式获取技能收益。

| 奖励池 | 基础概率 | 示例 |
|---|---|---|
| 稀有 | 2% | 铁、铜、煤、红石、青金石、紫水晶、海草、墨囊、经验瓶 |
| 史诗 | 0.5% | 少量钻石、海绵、海晶灯、鹦鹉螺壳、命名牌、附魔书、海风钓竿 |
| 珍藏 | 0.08% | 潮汐钓竿、修补之书、海洋之心、三种命名唱片 |

稀有和史诗仍会受到相应技能能力影响，表中不是所有玩家的最终概率。珍藏池不增加幸运倍率，奖励按池内权重选取；不额外发金币，不加入下界合金、鞘翅或不死图腾。关闭 `loot.update_loot_tables`，避免上游默认表覆盖定制奖励。维护时改模板并停服合并到实际配置，更新插件前保留自定义表备份。

已补齐圈地日常操作提示、菜单和服务端 MOTD；管理员诊断日志及未启用的高级围攻提示保留上游文本。中文菜单实际显示和钓鱼体感仍需部署后使用 Java/PE 客户端检查。

## 0.9.4 指南针布局

主菜单缩为 45 格，核心功能采用居中的五列三排：第一排主城、生存、创造、家园、好友传送；第二排领地、伙伴、交易、钱包、生电；第三排技能、钓鱼、礼物、互动、我的成长。底栏只放新手手册、关闭、账号绑定。暖棕边框与侧面的三色分区标记保持整齐；PE 原生表单仍读取同一按钮顺序，不显示装饰格。

首次启动自动迁移已知菜单项位置，旧配置保存为 survival.yml.before-layout-v094，保留原有按钮动作与本地文案。有额外自定义功能或装饰格自定义动作时不覆盖布局，按 pending 新模板手工合并。
