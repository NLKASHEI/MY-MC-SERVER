## 已知限制

EssentialsX 使用官方开发构建 `2.22.1-dev+27-e70bdb8`，因为正式版 2.22.0 在 26.2 上报告不支持。当前已启动验证，但后续更新仍需兼容性检查。

DeluxeMenus 的旧 NBT 扩展选项在此版本没有 NMS hook；本项目菜单没有使用那些选项。测试电脑的 Windows 性能计数器报错只影响系统信息采集；AuthMe 在未提供 GeoIP 凭据时有下载提示，当前地区保护关闭。这些问题没有阻止服务端就绪。

商店 v7.3.2 的 `lang-zh_cn.yml` 语言标识在测试中回退到英文。当前使用官方中文文本作为 `LanguageFiles/lang-en.yml` 的内容，保留插件识别的文件名，复测不再产生语言回退错误。更新时需要保留或重新核查此兼容处理。

独立目录的首次启动曾遇到商店基岩图标下载超时。完整部署包附带已获取的四份公开物品、纹理映射缓存，避免首次依赖该下载；缓存到期仍需联网刷新。从源码安装时如出现此提示，应确认图标源可访问，不能据此认定基岩商店界面已经验收。

当前是中文基础配置，圈地的高级管理员、围攻等低频消息仍有英文。管理员诊断日志保留上游文本。

## 仍需客户端验收

本机没有进行真人 Java 与基岩账号的完整入服操作测试。端口响应不等于所有登录和 GUI 交互已经验收。上云后用两个真实客户端依次验证：

1. 未登录不能移动、打开菜单或执行奖励命令；注册、密码登录和改密正常。
2. Java 与基岩玩家名字及 UUID 分离，重进保持背包、金币和圈地。
3. 指南针、菜单、商店购买、付款、家和传送申请。
4. 两名玩家测试圈地建造、容器和授权，野外火焰及爆炸按生存规则运行。
5. 在线奖励各档仅领取一次，重启保留记录，跨日按上海时区重置。
6. 备份还原、CoreProtect 查询及小范围回滚。
7. 普通账号进入主城后不能挖建或战斗，指南针三个世界按钮均可点击，PE 客户端可操作菜单；空手坐台阶、骑头、潜行退出和拒绝被骑乘正常。
8. 将命名物品、装备、副手、末影箱、经验和药水分别放入生存/创造世界，反复用菜单、家和 TPA 切换、退出并重启，确认互不污染，主城购物物资能带回生存。
9. 创造世界不能通过命令别名或命名空间命令交易、转账或领取奖励；跨世界骑乘和传送门不携带创造载具或物品。

本次没有安装反作弊、没有大范围预生成、没有部署云服务器或修改云安全组。
