- Windows PowerShell 5.1 的语法校验及候选更新查询通过。候选查询未替换任何组件。
- 43 个 YAML 配置模板可解析，圈地的 49 条常用中文提示保留原有编号占位符。三个维护技能通过 skill-creator 的校验器。

## 已知限制

EssentialsX 使用官方开发构建 `2.22.1-dev+27-e70bdb8`，因为正式版 2.22.0 在 26.2 上报告不支持。当前已启动验证，但后续更新仍需兼容性检查。

DeluxeMenus 的旧 NBT 扩展选项在此版本没有 NMS hook；本项目菜单没有使用那些选项。测试电脑的 Windows 性能计数器报错只影响系统信息采集；AuthMe 在未提供 GeoIP 凭据时有下载提示，当前地区保护关闭。这些问题没有阻止服务端就绪。

商店 v7.3.2 的 `lang-zh_cn.yml` 语言标识在测试中回退到英文。当前使用官方中文文本作为 `LanguageFiles/lang-en.yml` 的内容，保留插件识别的文件名，复测不再产生语言回退错误。更新时需要保留或重新核查此兼容处理。

当前是中文基础配置，圈地的高级管理员、围攻等低频消息仍有英文。管理员诊断日志保留上游文本。
