# 严格立体领地

0.9.8 起，新领地使用已有 WorldGuard 的立体区域保护，MiaoServer 管理中文菜单、私人选区粒子、申请和队伍授权。生存主世界、下界、末地均可圈地，主城、创造世界和公共出生点不能圈地。

## 选区和创建

金铲右键两个立体对角点，包含高度；左键重选第一个角点。绿色粒子为合规范围，红色表示至少一条边超过上限，只有选择者能看见。选区两分钟过期；木棍右键已有立体领地查看三维轮廓，显示三十秒。

指南针 → 领地管家 → 确认创建选区。长、宽、高各自最多 25 格，两个角点都计入尺寸：坐标差 24 是 25 格，差 25 是 26 格。盒子上下均不受这块领地保护；不重叠的上下两块领地可由不同玩家拥有。不与已有领地或公共保护区重叠。

更大选区先在同一菜单点“申请更大领地”，系统给出编号。OP 用 `/land requests` 查看，再用 `/land approve 编号` 或 `/land deny 编号` 处理。普通玩家不能自行批准；OP 直接确认也可超过上限。批准时再次检查重叠。每块领地限制尺寸，目前未限制总块数，也不提供自动扩建或合并旧领地。

## 信任和队伍

地主站在自己的立体领地内使用 `/land trust 完整玩家名` 授予建造、箱子和交互权限，`/land untrust 完整玩家名` 撤销手动信任。菜单有说明入口和授权名单。立体领地内 `/trust`、`/untrust` 同样转到这个流程，不影响旧领地。精细容器、访问或管理授权命令仅用于旧领地，立体领地不会把这些命令误升为建造权限。

队员均可邀请在线、已登录且未组队的玩家；指南针伙伴小队的邀请按钮打开 PC 玩家头像列表，PE 打开原生玩家列表，支持翻页。目标需自行接受，邀请五分钟有效、默认八人上限。踢人、解散仍限队长。

队伍共享操作只允许地主，地主不必是队长。取消共享只允许地主和 OP，撤销自动队伍权限、保留独立手动信任和建筑；成员没有转让、删除和再次授权权限。离队、踢出或解散自动同步；单人队伍保持共享设置，后续加入的成员会获得权限。转让会结束原队伍共享，保留手动信任。

`/land delete confirm` 删除当前位置立体领地保护，建筑不删除，必须地主或 OP；指南针放弃按钮另有确认页。`/land transfer 完整玩家名` 转让，`/land list` 查看自己的立体领地。请用这些入口维护授权，直接修改 WorldGuard 成员表不会写入手动信任记录。

## 旧领地和数据

已有 GriefPrevention 领地维持原保护和权限，不自动改成 25 格高，也不删除玩家存档。停用自动箱子新领地，普通玩家不再通过旧插件创建；旧工具改为铁锄，供管理员处理遗留区域。旧领地仍可 `/trust`、`/untrust`、`/claimslist` 和原组队共享。

立体区域保存在 WorldGuard 的世界区域数据，所有者、手动信任、队伍来源与申请保存在 `plugins/MiaoServer/claims-3d.yml`。两者随现有备份一起保存，更新包不包含它们。版本升级首次启动只迁移圈地工具、权限和相关菜单键，保存旧配置副本。

本地 Paper 实际启动与模拟权限检查已覆盖三轴尺寸、上下边界、叠层领地、陌生人破坏/放置/箱子限制、非队长共享、地主/OP 取消、手动信任保留、成员新增修复、超限审批和睡眠规则。真实 Java/PE 的粒子、头像外观、点击与授权还需云服玩家验收。
