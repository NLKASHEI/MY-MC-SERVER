# 丰饶矿界与深层创造超平坦

## 玩家入口与费用

指南针 → 世界探索 → 丰饶矿界 → 确认入场。Java 使用 DeluxeMenus 可视化面板，PE 使用同一配置生成的原生按钮表单；可从这里返回生存、查看资源费和下次重置时间。原版生存、主城和创造超平坦按钮保留，四个世界按钮均匀排布。

每次从其他世界进入矿界收 100 金币，直接传送、TPA、`/back` 等同样逐人检查。没有余额取消传送；扣款后若被其他插件取消，正常情况下两 tick 后退款。在矿界内部传送和同一次停留断线重连不重复购票。重置会终止旧门票，重新入场重新购买；不会要求在离开时再付金币。

矿界 `minecraft:mining` 使用生存模式，与主城、生存三维度共用 `survival` 背包组；创造 `flat` 仍为独立组。含物品、装备、副手、末影箱、经验及既有组内分享项；金币本来就全服共用。仅向原组添加矿界，不清空或导入玩家个人档案。

## 丰富矿藏与资源费

原版地形和原版矿石分布基础上，为新增区块的天然矿脉随机扩展相邻矿石，目标约增加 50%。仅把相邻石头/深板岩改成对应矿石，不覆盖空气、建筑或已生成区块；空间受限时实际增幅略低，属于概率增量，不保证每块矿脉严格增加一半。

按服主确认方案，在天然矿石实际掉落中预留资源费，离开只显示结算，不再扣背包。时运按实际掉落数量计算，精准采集按掉落矿石块计算。每个 UUID、每种物品累计三份留一份：八个钻石预留两个；余数二保留，之后再产出一个钻石预留一个。余数跨重连、重启、重新买票和世界重置保留，避免拆分采集免税。

收费范围为煤、粗铁、粗铜、粗金、红石、青金石、钻石、绿宝石及对应普通/深层矿石块。石头、泥土、木材等不收费。不是扫描背包资产，不扣进入前随身携带的物资；玩家放置的矿石有区块持久化来源标记，再挖不收税，活塞搬运随同移动来源标记。正常采矿在掉落时扣除，爆破天然矿产在首次拾取前预留；漏斗等自动采集使用独立自动化余数，不计入个人出界统计。禁止经矿界传送门把未结算爆破物品送去其他维度。

已经预留后的物品可以自由合成、存箱或交给队友，死亡和换一种返回方式不会再次扣费。结算显示的是本次矿产掉落总量与预留数量，不表示当前背包里一定还有多少物品。账本按五秒保存，并在进出、退出和停服保存；突然断电不具备跨插件数据库和世界文件的原子事务保证，不能当作强一致金融账务。

## 每三天北京时间凌晨四点重置

首次启用，以服务器当前北京时间的日期加三天，凌晨 04:00 为第一次；以后从已保存的计划每次加三天，不因重启推迟。计划写在运行数据 `plugins/MiaoServer/mining-ledger.yml` 的 `next-reset`。停服错过多个周期，下次启动补做一次，再向后计算最近的未来计划。

重置前约十分钟、五分钟、一分钟和十秒提醒。到时暂停入场，把在线玩家送回生存安全出生点，确认矿界无人后仅删除 `world/dimensions/minecraft/mining`，通过 Multiverse 原生 API 用新随机种子重新创建。清空矿界建筑、箱子、掉落物和生物；保留账号、金币、随身生存背包、其他世界与矿产余数。离线矿界访问记录结束，后续登录提醒重新购票。种子保证与上次不同；不自动复制旧矿界作为额外备份。

**不要在矿界建家。** 入口、入场、状态和重置广播都会提醒；禁止 `/sethome`、设置公共传送点和床/重生锚重生点，领地功能不在矿界启用。临时插火把、搭桥、放箱子仍可以，必须在重置前自己带走箱内物资。矿界初始边界直径 6000 格，出生点为受现有八格范围保护的安全平台。

远景兼容：对锁定的 DHSupport 0.14.0，在热创建矿界的 WorldInit 阶段先注册原生世界适配器，避免出生区块生成事件早于 WorldLoad 时出现空世界接口；随后仍由 DHSupport 正常处理加载和卸载。

## 超平坦一次性清空

服主明确确认旧超平坦无人使用，允许直接清空、不额外备份该维度。0.9.18 首次启动仅重建 `minecraft:flat`，关闭村庄等结构生成，关闭湖泊/装饰；从 Y=-64 起共 128 层：一层基岩、124 层石头、两层泥土、一层草方块，地表 Y=63，出生脚下位置 Y=64。保持创造模式、和平、创造背包隔离。

完成标记为 `plugins/MiaoServer/flat-reset-v0918.done`。**不要删除此标记。** 日后更新和矿界周期重置均不会再次清空超平坦。标准一键更新仍执行原有停服备份流程，此功能不额外建立超平坦备份。

## 维护与验收

配置来源 `config/survival/plugins/MiaoServer/config.yml` 的 `resource-world`：`entry-fee`、`tax-divisor`、`ore-bonus-percent`、`border-size`、`reset-period-days`、`reset-hour`。首次迁移只补缺失默认值，保留已有其他配置；已有矿界边界不会每次启动重设。改动收费规则或周期时同步菜单文字；已经写入的下次重置时间不会因普通重启重新计算。账本、区块 PDC 和初始化标记是本地运行数据，不提交 Git、不由模板覆盖。

本地检查覆盖实际深层地形、结构关闭、矿界与创造分组、菜单注册、八钻石扣二、放置矿石免税、约 50% 矿脉扩展、插件传送门票、余额不足、取消后退款及实际换种重建。Java/PE 双客户端入场、TPA 操作和背包往返仍需上云验收，测试代理玩家不等同于真实客户端。

实现依据：[Multiverse 世界管理 API](https://mvplugins.org/core/developers/api-usage/)、[背包分组 API](https://mvplugins.org/inventories/developers/api-usage/)、[Paper 26.2 世界创建 API](https://jd.papermc.io/paper/26.2/org/bukkit/WorldCreator.html)。
