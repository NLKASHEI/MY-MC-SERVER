# 昵称与私人备注

指南针 → 账号与双端绑定 → 昵称与私人备注。Java 使用物品菜单与私密聊天输入，PE 使用原生表单。头像列表展示在线玩家及已备注的离线玩家，支持分页。

- 公开昵称用于聊天、TAB 玩家列表与自己的侧边栏，手机玩家仍保留 `[PE]` 标记。
- 0.9.17 起聊天使用本服昵称来源，避免其他插件临时改写显示名造成 `.名字` 再次出现。私人备注仍只对设置者显示。
- 在线 PE 玩家在常用选人指令中可写 `[PE]实际名字`，例如 `/tpa [PE]Steve`、`/pay [PE]Steve 100`、`/msg [PE]Steve 你好`、`/mteam invite [PE]Steve`。这里使用账号名，不使用自定义昵称或私人备注；账号有空格时改用下划线，已绑定账号使用 `[PE]Java账号`。支持 Bukkit 补全事件的指令会添加对应候选；部分客户端原生命令补全仍可能显示实际账号。
- 此兼容层只处理传送、私聊、转账、信任、组队及备注的明确玩家参数，保留原命令权限、认证和保护检查。实际账号仍为 `.名字`，原写法也有效；控制台、离线管理及其他第三方指令继续使用实际账号名。不改 Floodgate 前缀或迁移 AuthMe 数据库。
- 私人备注用于本人收到的公共聊天、队内聊天与队伍邀请头像列表，其他玩家看到公开昵称。TAB 列表展示公开昵称，不展示私人备注。
- 中文、字母、数字、空格、下划线和短横线最多 16 字，不允许颜色代码。聊天名称悬停可查看真实账号。
- Java 菜单输入两分钟有效，输入“取消”退出、“清除”删除；这条输入不会广播。PE 留空恢复或删除。

命令：`/miao names` 打开中心；`/miao names nick 昵称` 修改自己的昵称，省略昵称恢复原名；`/miao names note 实际账号 备注` 给曾进服账号备注，省略备注删除。指令始终按真实账号找人，昵称不会变成账号别名。

昵称与备注保存在 `plugins/MiaoServer/player-names.yml`，按 UUID 绑定，备注还按设置者 UUID 隔离。它属于玩家数据，随插件数据备份，更新包不包含此文件。绑定后的双端使用同一 UUID，自然共享自己的设置；绑定前的两份身份不自动合并。

旧服更新只在账号菜单已知空白装饰槽添加入口，自定义占用时保留原按钮，可用命令打开。PC/PE 真实客户端的表单与聊天显示仍需服内验收。
