# Windows 云服务器使用指南

## 启动与网络

完整部署包自带 Windows x64 Java 25。解压到本地磁盘，阅读 https://aka.ms/MinecraftEULA，接受后将 `servers/survival/eula.txt` 设为 `eula=true`，双击 `启动服务器.bat`。

`server-settings.json` 中初始堆内存 2GB、最大 6GB，只是可调模板，不代表已按某台云服务器容量优化。必须给 Windows 留出内存。人数和硬件确定后再调视距、模拟距离、预生成范围。

云安全组和 Windows 防火墙开放 Java TCP 25565、基岩 UDP 8585。当前 Geyser 使用 RakNet 监听；以后启用 NetherNet 时需要按其配置重新核查 TCP/UDP 和公告地址。本项目没有修改测试电脑的防火墙。

Java 玩家填写 `s9-4.yxjsmc.cn:20005`；基岩填写地址 `s9-4.yxjsmc.cn`、端口 `20013`。用户已向云商确认映射支持 TCP+UDP；客户端须符合 Geyser 支持范围。手机使用可手动添加服务器的基岩版客户端。

## 账号与权限

当前 Java 与基岩玩家均需首次 `/register 密码 重复密码`，以后 `/login 密码`。Floodgate 验证基岩身份，AuthMe 处理服内密码。基岩底层账号名保留 `.` 前缀和空格替换规则，聊天、列表与侧边栏显示 `[PE]`，不改变已有登录账户。

已启用 Floodgate 本地 SQLite 绑定，关闭全局绑定，没有按前缀自动登录。绑定后 PE 使用 Java 主账号的数据与密码；旧 PE 数据不会自动合并。详见 [双端与生电指南](crossplay-technical.md)。离线 Java 可选择的名字需要由注册密码保护。首次开服先注册管理员账号，再从服务端控制台 `op 账号名`；上线稳定后用 LuckPerms 单独分配管理员权限。不要给普通玩家管理通配权限。

普通权限来自 `permissions.yml`。LuckPerms 用于以后设置管理员、赞助等级等角色。不要给玩家 OP 来解决某个功能缺权限的问题。

## 生存功能

- `/menu` 或 `/cd` 打开中文服务中心；登录进入和切换世界后补发菜单指南针，丢失可 `/guide compass` 领取。
- `/worlds` 或 `/sj` 打开中文世界选择菜单，`/hub` 返回主城。主城、生存、创造超平坦均可直接点击切换。
- `/sethome 家名`、`/home 家名`、`/delhome 家名`，默认最多三个家。
- `/tpa 玩家`、`/tpaccept`、`/tpdeny`，传送等待三秒。
- `/balance`、`/pay 玩家 金额`，新玩家初始 100 金币。
- `/shop` 购买常用物资，当前六种物资，仅购买；收购和玩家商店后续按经济方案添加。
- `/reward` 领取每日活跃在线奖励，30/60/120 分钟分别奖励 50/100/200 金币，每档每日一次。以每分钟采样位移超过一格判断活跃，重启后领取记录保留，每日以 Asia/Shanghai 重置。这是轻量活跃判断，不能保证识别所有挂机方法。
- 金铲右键两角圈地；木棍查看；`/trust 玩家` 和 `/untrust 玩家` 管理好友；`/claimslist` 查看。初始 500 格，每小时增加 100 格。关闭自动过期，不因长期未上线自动释放家园。
- `/fun` 打开互动菜单；空手右键台阶/半砖/地毯坐下，右键玩家骑头，最多叠 3 人。潜行站起或甩下乘客。`/sit playertoggle` 开关被骑乘，`/lay` 躺下、`/crawl` 爬行、`/spin` 转圈。
- `/skin` 使用皮肤功能，`/rules` 看规则。

新增 `/skills` 中文技能界面和 `/guide technical` 假人说明；技能在生存维度升级，主城与创造区禁用收益。假人每人一个、全服二十个，玩家离线十五秒后移除，保留其背包。未绑定 PE 名称包含特殊字符，假人命名需在双端绑定后使用 Java 名称验收。

默认死亡掉落，正常饥饿和原版进度，AuraSkills 会增强部分属性和能力。Paper 在部分红石、刷物品和复制行为上与原版实现不同；需要生电特性时另行核查设置。

## 管理与扩展

CoreProtect 记录方块和容器行为，管理员可 `/co inspect` 查询，回滚前用精确玩家、时间和区域筛选并备份。Chunky 供管理员按需预生成世界，当前未执行大范围预生成。Paper 自带 spark 性能分析器。

Multiverse-Core 管理主城 `lobby`、创造超平坦 `flat` 和生存 `world`/`world_nether`/`world_the_end`。主城与生存共享背包，主城受 WorldGuard 保护，不能挖建、战斗、丢弃/拾取物品或开公共容器。管理员有保护绕过权限，测试保护必须用没有 OP 的普通账号。

创造世界自由建造，使用 Multiverse-Inventories 隔离背包、装备、副手、末影箱、经验、生命、饥饿、药水效果及重生点；跨世界切换解除骑乘。金币全服共用，创造世界禁止商店、出售、转账和领取奖励，也不累计在线奖励分钟。不要向普通玩家授予任意传送、模式更改、保护绕过或背包绕过权限。

Paper 26.2 存档结构为 `world/dimensions/minecraft/`，所有维度都在同一 world 目录；备份要完整复制。主城模板来源及作者见 `assets/worlds/README.md`。原始蓝图范围较大，Chunky 预生成应按实际世界和云机容量选择，不自动全服预生成。

清理脚本每十分钟进入 60/30/10 秒预告阶段，只清超过两分钟的低价值普通掉落物：石头、圆石、深板岩圆石、泥土、地狱岩、腐肉、小麦种子。刚生成、玩家主动丢弃、死亡附近掉落、命名物品及未知年龄的实体跳过；不删除生物、村民、矿车、船、盔甲架。保护只针对额外清理，原版约五分钟自然消失仍生效。管理员可 `/cleanup` 手动执行同样的保守规则。

后续小游戏优先独立子服，避免背包、金币、奖励和圈地插件混用。见 `.agents/adr/0002-multiworld.md`。

## 修改配置

本地新服可将 `config/survival` 复制到运行目录。已有玩家的云服应逐项合并修改。`config` 不包含认证数据库、存档或密钥，不能拿它替代完整备份。

日常停服：控制台输入 `stop`，等待所有存档保存和 Java 退出；再备份、更新或搬迁。备份脚本会拒绝对正在运行的随包 Java 进行文件复制。

## 自动备份与玩家商店

Backuper 每 2 小时备份、保留最近 3 份；`/market` 打开玩家箱子交易中心。Java 遥远地平线使用匹配的 DH 3.2.0-b，PE 无该 MOD 效果。WorldEdit 已安装且仅管理员可用。详见 [备份、集市与远景指南](backup-market-dh.md)。

## 伙伴与侧边栏

服务器名为「南可熙的神奇妙妙服」。指南针左下角进入伙伴中心，组队可共享地主主动开启的领地，离队自动撤销队伍授权。侧边栏显示状态、在线人数、PING、游玩时间和队伍；`/sidebar` 开关，`/sidebar settings` 或指南针「我的成长」选择数据；设置随身份保存。详见 [伙伴指南](community.md)。

主城保护包括 OP 挖放和 WorldEdit 编辑；新版本首次登录送入主城一次，以后恢复退出位置。指南针右键打开菜单，管理员左键传送；PE 指南针使用原生按钮表单。
