# Windows 云服务器使用指南

“云峦筑境”是 0.9.25 新增的永久创造建筑世界，内部名 `architect`，普通原版地形，固定种子 `8176667507634209290`。指南针→世界探索→云峦筑境，或 `/mv tp w:architect`。独立 `architecture` 背包组，不与生存或超平坦共享背包、末影箱、经验；不收矿界门票或资源费，不定时重置。和平、允许飞行、关闭自然刷怪和火焰蔓延，禁用跨维度传送门和创造经济收益。相同种子下的具体景观仍需前往相同坐标查看。

云峦筑境和超平坦均为和平难度。建筑便利命令：`/tp 玩家名`（只移动自己，目标须在当前同一个建筑世界）、`/gamemode creative` 或 `/gamemode survival`（仅自己）、`/fly`（仅自己）。也可使用 `/miao build tp 玩家`、`/miao build mode survival`、`/miao build fly`。这些入口逐次核对当前世界和登录状态，离开建筑世界立即失效，不给普通玩家全局 TP、模式、天气、时间或管理权限。离开时撤销本功能的生存飞行；管理员已有权限不受影响。建筑区即使切为生存仍使用该区背包，不可交易、领取在线奖励或获得 AuraSkills 收益。

## 启动与网络

完整部署包自带 Windows x64 Java 25。解压到本地磁盘，阅读 https://aka.ms/MinecraftEULA，接受后将 `servers/survival/eula.txt` 设为 `eula=true`，双击 `启动服务器.bat`。

`server-settings.json` 按服主 16GB 机器设置初始堆内存 4GB、最大 12GB。已有云服更新后首次启动，只把原默认 `2G/6G` 合并为 `4G/12G`，保留其他字段并备份原文件。自行调整过的内存配置保留；已迁移后即使重新改为 `2G/6G`，也不会再次覆盖。

云安全组和 Windows 防火墙开放 Java TCP 25565、基岩 UDP 8585。当前 Geyser 使用 RakNet 监听；以后启用 NetherNet 时需要按其配置重新核查 TCP/UDP 和公告地址。本项目没有修改测试电脑的防火墙。

Java 玩家填写 `s9-4.yxsjmc.cn:20005`；基岩填写地址 `s9-4.yxsjmc.cn`、端口 `20013`。用户已向云商确认映射支持 TCP+UDP；客户端须符合 Geyser 支持范围。手机使用可手动添加服务器的基岩版客户端。

## 账号与权限

0.9.12 将 `bukkit.yml` 的 `spawn-limits.monsters` 基准调为 100（原为 70）。云服更新后首次启动自动合并，备份为 `bukkit.yml.before-mob-cap-v0912`，完成标记 `.mob-cap-v0912-applied`，其他类别与频率保留。Paper 的每世界 `entities.spawning.spawn-limits.monster` 为 `-1` 时继承此值；自行设过显式每世界上限的配置仍优先。提高基准不保证产量同比增加，留意多人在线时 TPS。

### TNT 复制

0.9.11 开启 TNT／地毯／铁轨复制、无头活塞、破基岩、末地传送门刷沙和绊线钩复制。已有云服停服后运行原有一键更新，再启动，由 `scripts/update-technical-settings.ps1` 只合并 `servers/survival/config/paper-global.yml` 的五个对应开关，保留其他配置；原文件备份为 `.before-technical-v0911`，完成标记为 `.technical-v0911-applied`，以后自行调整不会反复覆盖。新部署提供对应模板。保持原版红石实现和漏斗保护事件，保护区仍按原有领地规则处理活塞与爆炸。设置依据：[Paper 原版行为说明](https://docs.papermc.io/paper/vanilla/)。

0.9.21 起同 IP 注册数量不限，多个账号默认各自保留进度。可从指南针账号中心自愿选择同步，支持 PC↔PE、同 IP 的 Java↔Java 和 PE↔PE；验证对方密码后才生效，铃铛可关闭提示。

当前 Java 与基岩玩家均需首次 `/register 密码 重复密码`，以后 `/login 密码`。Floodgate 验证基岩身份，AuthMe 处理服内密码。基岩底层账号名保留 `.` 前缀和空格替换规则，聊天、列表与侧边栏显示 `[PE]`，不改变已有登录账户。

已启用 Floodgate 本地 SQLite 绑定，关闭全局绑定，没有按前缀自动登录。新版账号菜单支持选择保留 PE 或 PC 进度，验证另一账号的密码后共用所选 UUID；同 IP 仅提示候选，两份旧数据不叠加。两端重连后均使用 Java 账号的服内密码。详见 [双端进度同步](crossplay-sync.md)。离线 Java 名字由注册密码保护。首次开服先注册管理员账号，再从控制台 `op 账号名`；上线稳定后用 LuckPerms 单独分配管理员权限。

普通权限来自 `permissions.yml`。LuckPerms 用于以后设置管理员、赞助等级等角色。不要给玩家 OP 来解决某个功能缺权限的问题。

## 生存功能

普通出生点保护范围内，登录后的 OP 可以挖放方块、用桶和维护作物；普通玩家仍受保护。主城继续禁止所有玩家（包括 OP）修改。

- 指南针 → 世界探索 → 丰饶矿界：从矿界组以外进入收 200 金币，TPA、`/back` 等同样逐人收费；重连不重复购票。三个矿界维度均为和平，共用门票和生存背包。新区块改为连片矿脉，主世界石质层矿石覆盖约 30%，煤铁铜为主，每种矿产累计三份预留一份资源费，八个钻石预留两个；背包与生存共享。每三天北京时间凌晨四点换种重置，不要建家，建筑和箱子会清空。详见 [资源世界与超平坦](resource-world.md)。

- 指南针账号中心新增昵称与私人备注；支持中文显示名与好友备注，实际账号不变，详见 [昵称与备注](player-names.md)。

- `/menu` 或 `/cd` 打开中文服务中心；登录进入和切换世界后补发菜单指南针，丢失可 `/guide compass` 领取。
- `/worlds` 或 `/sj` 打开中文世界选择菜单，`/hub` 返回主城。主城、生存、创造超平坦均可直接点击切换。
- `/sethome 家名`、`/home 家名`、`/delhome 家名`，默认最多三个家。
- `/tpa 玩家`、`/tpaccept`、`/tpdeny`，传送等待三秒。
- `/balance`、`/pay 玩家 金额`，新玩家初始 100 金币。
- `/shop` 购买基础物资并收购矿产、农渔和掉落物；指南针交易中心提供出售窗口、玩家箱子商店与收入说明。天然矿石与亲手击杀怪物自动发金币，不必选职业，详见 [金币与交易](economy.md)。
- `/reward` 领取每日活跃在线奖励，30/60/120 分钟分别奖励 50/100/200 金币，每档每日一次。以每分钟采样位移超过一格判断活跃，重启后领取记录保留，每日以 Asia/Shanghai 重置。这是轻量活跃判断，不能保证识别所有挂机方法。
- 金铲右键选择两个立体对角点，普通新领地长、宽、高每边最多 25 格；粒子仅自己可见，在指南针领地管家确认。超过上限先申请 OP；已有旧领地继续保护。见 [立体领地](claims-3d.md)。
- 生存主世界入睡比例设为 51%，例如三人需两人、四人需三人入睡即可跳过夜晚；Java 与 PE 共用统计。AFK/隐身豁免沿用 Essentials 设置。
- `/fun` 打开互动菜单；空手右键台阶/半砖/地毯坐下，右键玩家骑头，最多叠 3 人。潜行站起或甩下乘客。`/sit playertoggle` 开关被骑乘，`/lay` 躺下、`/crawl` 爬行、`/spin` 转圈。
- `/skin` 使用皮肤功能，`/rules` 看规则。

新增 `/skills` 中文技能界面和 `/guide technical` 假人说明；技能在生存维度升级，主城与创造区禁用收益。假人每人一个、全服二十个，玩家离线十五秒后移除，保留其背包。未绑定 PE 名称包含特殊字符，假人命名需在双端绑定后使用 Java 名称验收。

生存主世界、下界和末地统一困难难度，死亡保留物品与经验，死亡回主世界有效床位或安全出生点。矿界独立为和平，死亡保留物品和经验并返回主世界，结算已预留资源费，重新进入需再买门票；主城为冒险模式。正常饥饿和原版进度，AuraSkills 会增强部分属性和能力。Paper 在部分红石、刷物品和复制行为上与原版实现不同；需要生电特性时另行核查设置。

## 管理与扩展

CoreProtect 记录方块和容器行为，管理员可 `/co inspect` 查询，回滚前用精确玩家、时间和区域筛选并备份。Chunky 供管理员按需预生成世界，当前未执行大范围预生成。Paper 自带 spark 性能分析器。

Multiverse-Core 管理主城 `lobby`、创造超平坦 `flat` 和生存 `world`/`world_nether`/`world_the_end`。主城与生存共享背包，主城受 WorldGuard 保护，不能挖建、战斗、丢弃/拾取物品或开公共容器。主城另由本服只读保护限制 OP 和 WorldEdit，不允许玩家或 OP 挖建；其他普通领地的保护验收使用非 OP 账号。

创造世界自由建造，使用 Multiverse-Inventories 隔离背包、装备、副手、末影箱、经验、生命、饥饿、药水效果及重生点；跨世界切换解除骑乘。金币全服共用，创造世界禁止商店、出售、转账和领取奖励，也不累计在线奖励分钟。不要向普通玩家授予任意传送、模式更改、保护绕过或背包绕过权限。

Paper 26.2 存档结构为 `world/dimensions/minecraft/`，所有维度都在同一 world 目录；备份要完整复制。主城模板来源及作者见 `assets/worlds/README.md`。原始蓝图范围较大，Chunky 预生成应按实际世界和云机容量选择，不自动全服预生成。

清理脚本每十分钟进入 60/30/10 秒预告阶段，只清超过两分钟的低价值普通掉落物：石头、圆石、深板岩圆石、泥土、地狱岩、腐肉、小麦种子。刚生成、玩家主动丢弃、死亡附近掉落、命名物品及未知年龄的实体跳过；不删除生物、村民、矿车、船、盔甲架。保护只针对额外清理，原版约五分钟自然消失仍生效。管理员可 `/cleanup` 手动执行同样的保守规则。

后续小游戏优先独立子服，避免背包、金币、奖励和圈地插件混用。见 `.agents/adr/0002-multiworld.md`。

## 修改配置

死亡重生优先保留原版验证过的有效床或重生锚：在下界、末地死亡也可返回主世界的床，有效下界重生锚仍正常使用。没有有效个人重生点时，下界与末地返回对应主世界，不使用维度默认出生坐标；主世界、主城、创造区仍在各自世界重生，创造与生存背包分组不变。末地出口保持原版返回位置。首次入服仍进主城，后续登录恢复退出位置。0.9.15 首次启动仅迁移 Multiverse/Essentials 相关重生键，保存 `.before-v0915` 配置副本，无需整份替换配置；若原版主世界位置被其他插件改写，回退时检查出生点附近可站立位置。

0.9.8 起 `/back` 和指南针好友传送中的「返回死亡点」读取最近一次死亡位置，经过 Essentials 的安全检查、3 秒等待与冷却返回；其他传送不会覆盖死亡目标。没有死亡记录时给出提示，危险落点可能被安全检查拒绝。保留跨世界背包隔离，不恢复已经消失的物品。

各世界公共出生点保护半径 8 格（17×17，全高度），普通玩家不能挖放，已登录 OP 可维护；爆炸破坏、活塞推进和水流灌入仍受保护；主城仍全城保护，床和重生锚不扩大保护区域。保护跟随当前世界出生坐标；可在 `MiaoServer/config.yml` 的 `spawn-protection` 修改半径或世界列表，停服重启生效。

本地新服可将 `config/survival` 复制到运行目录。已有玩家的云服应逐项合并修改。`config` 不包含认证数据库、存档或密钥，不能拿它替代完整备份。

日常停服：控制台输入 `stop`，等待所有存档保存和 Java 退出；再备份、更新或搬迁。备份脚本会拒绝对正在运行的随包 Java 进行文件复制。

## 自动备份与玩家商店

Backuper 每 2 小时备份、保留最近 3 份；`/market` 打开玩家箱子交易中心。Java 遥远地平线使用匹配的 DH 3.2.0-b，PE 无该 MOD 效果。WorldEdit 已安装且仅管理员可用。详见 [备份、集市与远景指南](backup-market-dh.md)。

## 伙伴与侧边栏

服务器名为「南可熙的神奇妙妙服」。指南针左下角进入伙伴中心，组队可共享地主主动开启的领地，离队自动撤销队伍授权。侧边栏显示状态、在线人数、PING、游玩时间和队伍；`/sidebar` 开关，`/sidebar settings` 或指南针「我的成长」选择数据；设置随身份保存。详见 [伙伴指南](community.md)。

主城保护包括 OP 挖放和 WorldEdit 编辑；新版本首次登录送入主城一次，以后恢复退出位置。指南针右键打开菜单，管理员左键传送；PE 指南针使用原生按钮表单。

## 右键收获与补种

已锁定 [Scythe 6.1.0](https://modrinth.com/plugin/scythe)，上游声明支持 Paper 26.2，MIT 许可。右键成熟的小麦、胡萝卜、土豆、甜菜、可可与地狱疣即可收获；补种需要背包中有对应种子或作物，并消耗一份，没有种子则仅收获。默认不用专用工具，未成熟作物不会收获。可从指南针 → 生电工具箱切换，也可输入 `/scythe toggle`。收获实际执行玩家破坏事件；另对收获和延迟补种检查 AuthMe、WorldGuard 立体领地、旧 GriefPrevention 领地、主城与公共出生点保护。普通玩家不能重载此插件。

村民蛋 5,000、掠夺者蛋 10,000 金币，生电器材分类购买，禁止回收与改造刷怪笼/试炼刷怪笼；掠夺者蛋不保证生成队长。玩家仍须通过正常玩法繁殖村民、获取其他稀有物品。

## 单人发包豁免

0.9.16 起支持 ViaVersion 的单人豁免，解决投影批量放置等操作可能触发 `You are sending too many packets!` 的情况。仅作用于被加入玩家的 ViaVersion 连接，不改变普通玩家或 Paper 自身的限制；若以后启用 ViaVersion 包大小限制，该连接开关也会豁免这一层大小限制。

已预置真实登录名 NLKASHEI：首次成功登录时绑定当前实际 UUID（包括此前双端绑定选用的身份），并持久保存。预置只执行一次，手动移除后不自动加回。未来更换共享 UUID 时可重新添加。账号未登录不能获得豁免；OP 身份本身也不自动豁免。

OP 在游戏内可用 `/packetallow add` 给自己加入、`/packetallow remove` 移除自己、`/packetallow list` 查看名单、`/packetallow status` 查看自己。加上在线玩家实际登录名或完整 UUID 可管理指定对象；控制台必须填写目标。未知离线名字不会创建虚构账号；已入名单的离线玩家可按保存的名字移除。授权其他管理员仅授予 `miao.packetallow.admin`。

名单在 `servers/survival/plugins/MiaoServer/packet-exemptions.yml`，首次写入时生成，属于运行数据，不进入 Git，也不被更新模板覆盖。不涉及密码、金币或存档；关闭插件会恢复由本功能更改的连接限流状态。
