# NLK：侧边栏、伙伴与领地

服务器名为「南可熙的神奇妙妙服」。Java 列表显示两行中文 MOTD 和温馨 MC 小屋图标，基岩版通过 Geyser 显示中文 MOTD。基岩服务器列表没有 Java 的自定义图标栏。

## 中文侧边栏

侧边栏标题为「欢迎游玩」，按「我的成长 / 服务器」分组，使用灰色标签和彩色数值，不显示底部命令。点击指南针的「我的成长」即可开关侧边栏并选择展示数据。Java 使用勾选界面，PE 使用原生开关表单。开关、所选字段和关注方块随 UUID 保存，重启、重登或切换已绑定客户端后保留。其他插件已有侧边栏时保留它，不反复争抢。聊天提示统一使用「南可熙提醒您：」。

内部插件名、数据目录和权限标识继续保留 MiaoServer / miao，以兼容已有玩家数据；玩家可见的服务中心描述和插件日志前缀使用 NLK。

最多选择十三项，包含真人在线数、PING、TPS/状态、世界、队伍、金币、总游玩时长、本次游玩时长、放置、挖掘、关注方块的放置/挖掘、击败生物、钓鱼、死亡和步行里程。提供状态与成长两套方案；Java 可点选常见方块，也可 `/sidebar block 方块英文ID` 自定义。

总时长首次从原版统计初始化，此后以成功登录后的实际在线秒数累计，避免创造背包组切换造成统计变化；本次时长从成功登录开始，断开后重置。包含挂机时间，不等同于奖励的活跃时间。放置/挖掘及指定方块从 v0.8.0 开始累计，只计真人在生存模式和生存维度的成功事件；取消的操作、假人、创造与主城都不计数。其他成长数据使用原版统计。

## 手机菜单与首次入服

PE 的十三个指南针菜单使用 Floodgate 原生按钮表单；读取同一份 DeluxeMenus 功能配置，避免手机版把 Java 箱子界面挤乱。技能、箱子商店等外部插件自己的界面仍由 Geyser 转换。操作回调返回服务器主线程，并再次检查 AuthMe 登录状态。

本版本首次完成登录后送入主城一次；以后恢复退出位置。新玩家的初始出生点也设为主城，Java/PE 共用规则。主城为冒险模式，独立拦截挖放、桶、爆炸、液体和 WorldEdit 改图；不因 OP 身份放行，修改主城需要停服维护。

指南针右键只开服务中心；有 `miao.compass.teleport` 权限的管理员左键可跳到视线目标上方。WorldEdit 导航工具改为追溯指南针，普通指南针不再触发其右键穿墙。

PE 在聊天、玩家列表和侧边栏显示 `[PE]`，未绑定的底层 Floodgate 名称仍保留原前缀。新版绑定时可选择 PE 或 Java 进度，详情见 [双端进度同步](crossplay-sync.md)；已绑定 PE 仍显示 `[PE]`。

## 一起安家

指南针左下角打开「伙伴小队」，领地管家也有入口。队名支持中文，默认一队最多八人，一名玩家只加入一队。

- `/team create 队名` 创建小队。
- 队长 `/team invite 在线玩家` 发出五分钟有效邀请，对方 `/team join` 接受。
- 地主在自己的生存主领地内 `/team share`，给队员建造和箱子权限。领地仍归地主，成员不能再授权；限制子领地需要单独管理。
- 地主可以是普通队员，不要求队长；只可共享自己拥有的主领地。已共享后再次点击会重新确认队友建造权限。0.9.8 把玩家 `/team` 和手机菜单动作统一路由到本服组队系统，避免与原版同名命令冲突；也可直接使用 `/mteam share`。公共出生点和主城保护高于共享建造权限。
- `/team unshare` 取消当前领地的队伍共享，只有地主或 OP 能操作；普通队友、队长都不能取消别人的共享。地主取消自己的共享不需要仍在队伍中。
- `/team chat 消息` 队内聊天；`/team info` 查看成员。
- `/team leave` 退出；队长 `/team kick 玩家` 可移除在线或曾入服的队员。
- 队长解散使用 `/team disband confirm`，菜单有二次确认。

退队、踢人、解散会自动撤回本插件授予的共享权限；共享前已经存在的手动信任会保留。地主退出后，其绑定领地也取消共享。不会删除领地、箱子或建筑。在共享期间再次对同一队员手动授予相同 Build 权限无法区分来源；想让其退队后仍保留建造权，先取消共享，再手动 `/trust`。0.9.8 修复领地转让后的自动授权残留，转让会终止原队伍共享并恢复原先手动信任，建议转让前先主动取消共享。

共享只授予建造和容器使用，领地所有权始终属于地主；队长管理队伍成员，不因此取得队员土地的所有权或授权管理权限。组队命令在登录后才可执行，遵守 `survival.team` 权限，不绕过公共出生点或主城保护。

成员和共享授权记录保存在 `plugins/MiaoServer/teams.yml`，属于玩家数据，禁止上传 Git，增量更新不会覆盖。邀请仅保存在内存中，重启失效。插件不带共享金币池或独立队伍物品仓库；组队不影响创造背包隔离。

## 备份调整与更新

本版本首次加载会只修改 Backuper 的自动周期为 120 分钟、本地保留数为 3，保留其他备份设置。迁移标记为 `plugins/MiaoServer/backup-schedule-v070.done`；完成后不反复改写管理员设置。自动存储只保留三份，更新前的完整备份另外保留，不受自动清理影响。

新插件和图标随锁定 JAR 更新，无需改旧版更新器的文件白名单，也无需覆盖存档。已自行修改的中文菜单仍按更新器规则保留，新模板写入冲突目录 `.new`；需要合并伙伴入口。

Paper 26.2 实际启动通过，PacketEvents 2.14.0 已加载，AuthMe 登录背包保护没有缺依赖警告。临时测试插件检查了共享授权、退队和解散撤权、保留原有手动信任与领地、侧边栏关闭/开启、中文 PING/时长，以及 OP 挖掘与 WorldEdit 不改主城。测试插件不进入发布包。手机原生表单显示、首次真人登录和真实 Java/PE 绑定仍需云端客户端验收。

JEI 显示 Paper 不提供 JEI 配方的英文提示来自客户端 MOD，不是服务端启动故障。无 MaxMind 账号的 GeoIP 检查已关闭，默认英文 AuthMe 欢迎语与 SkinsRestorer 通用启动器提示已收敛；密码登录与皮肤功能保留。

0.9.8 新增在线玩家头像邀请（队员也可邀请，PE 原生列表），新增严格立体领地；旧领地继续保护。具体规则见 [立体领地](claims-3d.md)。
