# 金币与交易

系统是金币发行者：首次入服赠送 100 金币，在线活跃奖励每日各档可领取一次，天然矿石开采与玩家亲手击杀指定怪物自动发放金币，系统收购物品也会发行金币。玩家转账和箱子商店只转移已有金币；购买系统物资会回收金币。

0.9.8 启用现有 AuraSkills 的收入功能，不必选择职业。每块煤矿 0.10、铁矿 0.15、金矿 0.50、钻石矿 2、绿宝石矿 3、远古残骸 5 金币，深层矿石同价。普通敌对怪物一般 0.30～0.50，烈焰人 1、恶魂 2、凋灵 20、末影龙 30。徒手与远程击杀分别由战斗、箭术来源处理；不奖励击杀玩家或普通动物，不按伤害重复发钱。其他技能、走路和受伤不产钱。

主城、创造超平坦不产生技能收入，创造模式禁用技能收益，创造区及创造/旁观模式禁止商店出售和转账。保留 AuraSkills 已有的玩家放置方块检查：玩家放下的矿石再挖不发该笔收入。不新增反作弊插件或开启反挂机检查；玩家亲手参与的刷怪塔仍可能产出少量金币。

指南针 → **系统商店**，直接打开四分类可视化面板，选择分类后点击商品即可查看价格、数量并购买或出售；Java 使用物品界面，PE 使用原生表单。系统商店内可进入玩家集市。直接输入 `/shop` 也打开同一面板，避免通用命令冲突。

面板功能：

- **系统商店**：原有基础补给，新增矿产交易、农渔收购、掉落物收购，共新增 39 项商品。价格按单件计算；农渔与掉落物为仅收购，矿产支持购买与出售。稀有装备不出售。
- **出售物品**：Java 与 PE 都可使用 `/sellgui`。只放入愿意卖掉的物品，关闭窗口即成交，不能撤销；不收购的物品退回。先在系统商店查看价格。
- **玩家箱子商店**：`/qs browse` 浏览；玩家自行定价、有库存才能成交，不由系统凭空补货。
- **金币从哪里来**：查看收入与钱包说明；`/balance` 查看余额，`/pay 玩家 金额` 转账。

模板在 AuraSkills `sources/mining.yml`、`fighting.yml`、`archery.yml` 中维护固定金额，默认来源收入为零；`MiaoServer/economy.yml` 记录旧服首次安装收入规则。系统商店使用 `EconomyShopGUI/shops/nlk_*.yml` 与对应 `sections`，收购价低于购买价，农场批量物品采用较低收购价。

旧服停服双击永久一键更新，再启动即可。首次启动仅合并相关收入键、安装三个新商店分类和可视化总面板、修正商店入口、追加出售按钮及权限，备份 `.before-v098`，不改金币余额、技能进度或其他玩家数据。后续手动调价不会被每次启动重置。若自定义菜单占用了预定出售按钮位置，保留原按钮，可用 `/sellgui` 或自行合并菜单。

已完成实际启动、收入来源解析与 PVP 零收入检查；真人挖矿到账、商店交易和 PE 操作仍需云服客户端验收。

配置依据：[AuraSkills 收入与放置检查](https://wiki.aurelium.dev/auraskills/main-config/)、[来源收入](https://wiki.aurelium.dev/auraskills/sources)、[系统商店命令](https://wiki.gpplugins.com/economyshopgui/basics/commands)。
