# 更新服务端

## What it does

核查和下载候选更新，停服后替换经过审核的组件并保留锁定版本。

用户日常使用 `一键更新.bat` 自动应用本项目正式 Release；独立更新包只带维护文件，插件按哈希增量下载。保留本地修改的配置和运行数据，提供 `.new` 冲突文件。按服主要求，0.9.23 起更新器不再执行整服备份；定期备份由 Backuper 负责。只临时保留变更文件以供复制失败撤回，成功后清理。维护者发布流程见运维更新指南。

## When to reach for it

Paper 或插件发布修复、基岩客户端升级后无法连接时。

## Common questions

会自动升级吗？不会。能直接升到 26.3 吗？需要单独审核协议和插件兼容性。失败如何回退？一键更新复制失败会撤回本次替换；启动后出现迁移问题，需要选用可用的定期或手动备份，更新器不提供整服还原点。

## It's working if

哈希校验通过、存档与本地配置保留、更新不调用整服备份；运行变更须启动无功能错误并完成客户端验收，清单记录正式使用版本。
