# 更新服务端

## What it does

核查和下载候选更新，停服备份，替换经过审核的组件并保留锁定版本。

用户日常使用 `一键更新.bat` 自动应用本项目正式 Release；独立更新包只带维护文件，插件按哈希增量下载。保留本地修改的配置和运行数据，提供 `.new` 冲突文件及完整停服备份。维护者发布流程见运维更新指南。

## When to reach for it

Paper 或插件发布修复、基岩客户端升级后无法连接时。

## Common questions

会自动升级吗？不会。能直接升到 26.3 吗？需要单独审核协议和插件兼容性。失败如何回退？恢复整个停服备份，不只换回旧 JAR。

## It's working if

哈希校验通过、备份完整、启动无功能错误、两端验收通过，清单记录正式使用版本。
