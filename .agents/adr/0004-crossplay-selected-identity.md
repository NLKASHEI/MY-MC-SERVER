# 0004：密码验证后选择双端进度来源

状态：已接受，2026-10-12。

服主要求同 IP 时提示同步候选，验证另一端服内密码后绑定，并允许以后手动绑定；PE 先玩时 Java 应能继承 PE，反之亦然。

保留现有 AuthMe 登录和本地 Floodgate SQLite。不以 IP/名字自动授权，不直接搬运多插件玩家数据库。绑定前选择共用的已有 UUID；PE 来源时使用 Paper 的登录资料接口将 Java 登录映射到该 UUID，Java 来源时采用 Floodgate 常规 UUID 共享。两端登录名采用 Java 名称，AuthMe 密码仍采用 Java 账号。

映射、原始双端 UUID 和进度来源写入持久日志，与 Floodgate 绑定回读共同确认。事务期间拒绝重连；启动核对未完成日志并阻止不一致身份进入。解绑协调撤销映射和 Floodgate 绑定，恢复两个原始 UUID。操作不复制、删除或叠加原有玩家数据；日志属于必须备份的玩家运行数据。

实际 Java/PE 客户端必须验收；新加名称存储插件应独立评估。内存按服主 16GB 云机设置 Xms4G、Xmx12G，已有云服仍保留本地 server-settings.json。
